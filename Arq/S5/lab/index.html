Aprende Virtualización y Linux

Descubre cómo instalar un sistema operativo dentro de otro. Entiende la arquitectura, el kernel, la memoria y la CPU desde la práctica.

¿Qué es Linux?

Es un núcleo (Kernel) de sistema operativo libre. Una distribución (como Ubuntu, Debian o Mint) empaqueta este kernel con herramientas y un entorno gráfico.

En este curso, Linux nos permite estudiar:

  • Administración de procesos y CPU.
  • Uso de memoria virtual.
  • Jerarquía del Sistema de archivos.
  • Usuarios, permisos y Kernel.

¿Qué es VirtualBox?

Es un Hipervisor de Tipo 2. Permite crear máquinas virtuales (VM) ejecutándose como una aplicación más sobre tu sistema operativo principal.

Requisitos y Descargas

Para Windows

  • Tener al menos 8GB de RAM física.
  • 25GB de espacio libre en disco.
  • Virtualización activada en BIOS/UEFI (VT-x o AMD-V).

Para macOS

  • Intel: VirtualBox funciona sin problemas.
  • Apple Silicon (M1/M2/M3/M4): VirtualBox 7.2 tiene soporte oficial, pero requiere ISOs ARM64. Si hay problemas, usar UTM o Parallels.
  • Permitir extensiones de kernel en Ajustes del Sistema > Privacidad y Seguridad.

Primer Inicio y Terminal

¡Felicidades! Linux está instalado. Ahora el Kernel de Linux está gestionando los recursos virtuales (CPU y RAM) que asignaste. Practiquemos comandos básicos que interactúan con el Sistema Operativo.

Comandos a probar:

Ubuntu 26.04 LTS (tty1)
alumno@virtual-os:~$ echo "Bienvenido a Linux"
Bienvenido a Linux
alumno@virtual-os:~$

Concepto: Apagado Correcto

Nunca cierres la ventana de VirtualBox usando la "X" mientras el sistema está encendido, equivale a desconectar el cable de energía de un PC físico. Esto puede corromper el Sistema de Archivos. Siempre usa el menú de apagado de Linux o el comando sudo poweroff.
